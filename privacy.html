Erne Fit – Privacy Policy / Política de Privacidad

Last updated / Última actualización: October 15, 2026

English

Erne Fit is a personal, single-user app used only by Ernesto Talamantes (talamantes.ernesto@gmail.com).

  • Data accessed: with explicit Google OAuth consent, Erne Fit reads the owner's own Google Health data: sleep, activity, heart rate/HRV, weight and nutrition.
  • Use: data is used solely to provide personal health coaching to the owner via a local MCP server (google-health-mcp).
  • Storage: data and tokens stay on the owner's private machine. No data is sent to third-party servers operated by Erne Fit.
  • Sharing: data is never sold, shared, transferred, or used for advertising.
  • Revocation: access can be revoked at any time at https://myaccount.google.com/permissions; locally stored data can be deleted by the owner at any time.

Google API Services User Data Policy: Erne Fit's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Español

Erne Fit es una aplicación personal de un solo usuario, utilizada únicamente por Ernesto Talamantes (talamantes.ernesto@gmail.com).

  • Datos: con consentimiento explícito vía Google OAuth, Erne Fit lee los propios datos de Google Health del dueño: sueño, actividad, frecuencia cardiaca/HRV, peso y nutrición.
  • Uso: exclusivamente para coaching de salud personal mediante un servidor MCP local (google-health-mcp).
  • Almacenamiento: los datos y tokens permanecen en la computadora privada del dueño.
  • Compartir: los datos nunca se venden, comparten, transfieren ni se usan para publicidad.
  • Revocación: el acceso puede revocarse en cualquier momento en https://myaccount.google.com/permissions.

Política de Datos de Usuario de los Servicios de API de Google: el uso y la transferencia de información recibida de las API de Google por parte de Erne Fit se apega a la Google API Services User Data Policy, incluidos los requisitos de Uso Limitado (Limited Use).
